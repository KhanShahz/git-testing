🌟 About The Project

Simple Calculator is a lightweight and responsive calculator interface designed with a clean and modern UI.

The project allows users to enter two numbers, select an arithmetic operation, and display the calculated result.

💡 A perfect beginner-friendly project for practicing HTML forms, CSS styling, and JavaScript logic.

🚀 Getting Started

Follow these simple steps to run the project locally.

1️⃣ Clone the Repository
git clone https://github.com/your-username/simple-calculator.git

2️⃣ Open the Project
cd simple-calculator

3️⃣ Run the Project

Simply open:

index.html


in your browser.

That's it! 🎉
